# 行政人力设计助手

面向行政、人力、企业文化与雇主品牌团队的中文设计 Skill。它帮助 AI 在做主视觉、海报与信息物料时先处理内容、版式、标题和真实资产的关系，避免落入通用办公模板。

## 能做什么

- 培训、年会、会议、竞赛、团建、文化月、周年活动主视觉与系列物料
- 活动通知、温馨提示、手机邀请函、报名/议程图
- 招聘海报、雇主品牌内容、优秀人员与团队表彰
- 奖状、证书、工牌及高信息密度的正式内部物料
- 接入公司 Logo、人员照片、奖项信息、场地照片、既有IP与品牌规范

## 设计原则

它不固定套用“科技蓝”“红金”或卡片模板，而是先判断传播任务与信息优先级，再选择适合的画面骨架、字体行式、媒介、颜色和材质。对通知、招聘、表彰、证书等事实型物料，额外强调姓名、日期、Logo、照片、奖项和行动路径的准确性。

## 使用方式

将 `administrative-hr-design` 文件夹放入你的 Codex skills 目录，或在支持 Skill 的工作环境中安装后直接描述需求。

示例：

> 为公司年度培训营设计 3 个手机主视觉方向。主题是「向新而学」，对象是入职 1–3 年员工，需要留出 Logo 安全区，风格明快但不要科技模板感。

用户明确说“按流程走”时，Skill 会先给出有实质差异的创意方向；说“直接做”时，会基于已有信息直接完成首稿。
