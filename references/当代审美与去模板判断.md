# 当代审美与去模板判断

## 判断作品是否成立

看关系而非风格标签。一个“高级”的行政人力视觉应同时有清晰的信息重心、与内容相关的视觉依据、可辨识的标题/图像关系和足够完整的细节控制。极简并不等于空，热闹也不等于俗；两者都要有可解释的尺度、节奏与主从。

## 常见失效与修复

| 失效 | 根因 | 优先修复 |
| --- | --- | --- |
| 像通用活动模板 | 内容没有改变画面 | 用活动机制、真实场地/人群或标题语义重建主体 |
| 标题只是在背景上加字 | 未先处理字块与阅读顺序 | 重做断句、尺度、位置与图文接触关系 |
| 很满但没有重点 | 装饰和信息同等响亮 | 降低无关元素，对主标题/行动建立对比 |
| 很空但不精致 | 留白没有被材料或结构承重 | 用真实纹理、光影、边界、摄影裁切或字块尺度建立重心 |
| 仪式感过度 | 金属、光效、奖杯变成全部内容 | 保留一种主材料，改用版式、边界和人/成果叙事支撑荣誉 |

不要把单次反馈扩展为永久禁令。例如红金在春节、庆典、喜报和东方主题中可非常有效；关键在红与金的比例、材质、留白、标题精度和项目关联，而非颜色名称本身。
