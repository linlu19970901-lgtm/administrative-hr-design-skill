# 真实资产与制作验收

## 素材接入

Logo、人物肖像、部门标识、奖杯、场地、截图和活动IP先判断其性质：是否必须原样保真，是否可作风格化背景，是否可裁切，是否涉及肖像授权。人物是主体时，先检查表情、姿态、边缘、服装与身份线索，再考虑调色和图文覆盖。

## 品牌区

没有明确VI时，默认将品牌区放入画面中稳定、对比充足、不会被裁切的位置；它不是随手贴在角落。首稿可让Logo与整体画面一起生成；发现形状、文字、颜色、比例、位置或清晰度有问题时，再用官方资产修复。需要后续人工置入时，使用明显但不破坏构图的空白安全区，并说明其位置和比例。

## 成稿检查

逐项核对：错别字/断句、姓名与称号、日期与星期、地点、部门名、Logo版本、照片人脸、二维码/链接/电话、裁切安全区、对比度与阅读顺序。印刷物另检查出血、最小文字与大面积深色风险；屏幕物另检查小屏阅读与第一屏行动。

若最终图中的文字由生成模型产生，必须逐字核对。发现实际错误时，再采用可编辑排版或局部编辑修复；当前工具无法可靠修复时仍可展示首稿并明确未解决项，不把有明显事实错误的试生成稿当成可直接发布文件。最终视觉始终把文字当成构图组成部分。

## IP 与人物的双重核对

IP先定义传播职责：英雄主体、叙事参与者、栏目主持或信息向导；每张只确定一个主职责。再按“识别核 → 动作剪影 → 道具/服装 → 环境接触 → 文字关系”制作。识别核可包括头身比、轮廓、五官、发饰、胸标和品牌色；不因统一画风随意改掉。

人物照片先看身份、表情、姿态、制服和边缘。需要艺术转译时保留可识别身份；如不能保证，改用非人物方向或将照片作为后置合成素材。所有官方标志、人物及IP都需在最终输出中再核对一次。
